# TiddlyWiki Plugins

A collection of TiddlyWiki plugins.

## Plugins

- **[advanced-search](./demo/plugins/advanced-search)**: An advanced search plugin for TiddlyWiki.
- **[code-copy-button](./demo/plugins/code-copy-button)**: Adds a copy button to code blocks.
- **[image-preview](./demo/plugins/image-preview)**: Enables image preview functionality.
- **[publisher](./demo/plugins/publisher)**: Tools for publishing TiddlyWiki content.

## Usage

To install dependencies:

```bash
bun install
```

To run the development server:

```bash
bun run serve
```

To build the project:

```bash
bun run build
```
